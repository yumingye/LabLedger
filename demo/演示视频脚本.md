# 真实软件演示脚本（约 4–6 分钟）

00:00 首页：数迹 LabLedger 为个人实验提供记录、质量检查、统计与图表的一体化工作空间；本地运行，无付费 API。

00:20 创建「课堂测量实验」，新建数字、文本、日期字段，录入两条记录并保存；演示更新和删除记录。

01:00 加载模拟冷却实验，明确说明全部数据为程序生成，预设质量问题用于演示。进入质量中心，展示缺失、重复、范围和无效日期；说明不会自动删除。

01:40 展示均值、标准差、方差以及最小二乘趋势；指出样本口径与异常候选仍参与计算的边界。

02:15 分别生成折线图、柱状图、散点图；选择组别、主题、轴标题；折线或散点开启趋势。下载 PNG，添加自定义图表到仪表盘。

03:10 仪表盘调整列数、顺序并保存。导出数据 CSV、原始 JSON 与统计结果，打开实际导出文件核对中文与行数。

04:00 停止应用并重启，展示相同项目、记录和仪表盘，说明 SQLite 持久化。最后展示真实自动化测试输出与交付包校验。

自动化录制若存在，仅记录真实浏览器运行过程，无配音；不替代参赛者最终讲解与录屏。提交前按本脚本人工复核并加入真实团队介绍。
