# 录制操作清单

- 运行 start.ps1，打开本地地址，建议 1440×1000 或常见笔记本分辨率。
- 浏览器下载位置设为 D:\数迹实验数据工坊\exports，避免默认下载到 C 盘。
- 确认使用模拟数据，无个人信息、密钥及其他项目出镜。
- 完成创建→录入→修改→删除→CSV 导入→质量→统计→三图→仪表盘→CSV/PNG 的完整闭环。
- 点击实际下载并检查文件，不用预制图片冒充软件画面。
- Ctrl+C 停止进程，再启动并验证记录与配置恢复。
- 无法录屏时仅提供此清单与真实截图，明确标记视频缺失。
- 自动化浏览器录制输出在 demo/recordings，转换 MP4 后验证可解码；不是桌面全屏录制。
- 最终配音、字幕、真实团队参与排序与参赛规则审核：待参赛者完成。
