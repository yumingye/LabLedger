基线：原始V1三提交 → V2冻结cf9bd26 → 冲奖串行三轮；V1/V2 ZIP、视频和清单均保留。

第一轮：按实验条件清洗、重复坐标均值趋势、正确热力图轴、报告缓存失效与唯一归档。
第二轮：自包含数字档案、SHA256、可重执行清洗/模型、差异检测；分条件异常诊断；实验假设/目标/结果与t区间对照。
