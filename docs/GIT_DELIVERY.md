## 用户确认后的操作

1. 确认参赛要求、真实团队信息、源码授权方式和私有/公开范围。
2. GitHub：由用户执行 gh auth login，或在 Gitee 设置真实 SSH/HTTPS 认证。
3. 在目标平台创建仓库，审核可见性；随后 `git remote add origin <用户确认的仓库地址>`。
4. 再检查 `git status`、`git ls-files`，确认无数据、环境、密钥和不应公开的材料。
5. 用户明确授权后才执行 `git push -u origin main`。

ZIP 提供源代码、文档、测试、截图及演示证据；完整本地提交历史保留在 `.git`，并另外提供 Git bundle（若成功生成）。源码包内不含 `.git` 的工作站配置或凭证。
