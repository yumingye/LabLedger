# 使用教程

1. 在项目根目录运行 `powershell -ExecutionPolicy Bypass -File install.ps1` 安装依赖；已安装环境可直接启动。
2. 运行 `powershell -ExecutionPolicy Bypass -File start.ps1`，访问 http://127.0.0.1:8501。保持启动终端运行，Ctrl+C 关闭。
3. 左侧创建实验，或点击「一键加载模拟实验」。每次加载创建一个独立模拟项目。
4. 展开「实验设置 / 新建数据表」，填写字段名、类型、数值范围；表格末行可添加字段，选择行号删除字段。名称不能重复。
5. 在「数据记录」中展开「逐字段编辑（自动保存）」，选择行号并按 Enter 提交单元格值。也可使用上方表格，或展开「单条记录操作」新增、更新和删除。看到自动保存反馈后即可刷新。遇到另一个窗口已保存新版本时，页面会提示本次编辑未保存。
6. CSV 导入：下载字段模板；以完全一致的表头填写数据；上传后检查预览，选择追加或替换，再确认导入。类型错误保留原值，在质量中心检查。
7. 「搜索与筛选」支持全字段搜索、单字段值筛选、按类型排序；可导出筛选后的视图，原表不会被改变。
8. 「质量中心」查看行号和问题，返回数据记录修改。IQR 异常只是候选，不能据此认定实验错误。
9. 「统计分析」查看样本统计、选择趋势 X/Y；非数值和非有限值不会参与计算，原始记录保留。
10. 「图表工坊」选择三种图表、坐标、分组、标题、主题；更多样式中调整轴标题、点样式、网格、图例和尺寸。PNG 下载与添加仪表盘均为真实操作。
11. 「仪表盘」选择 1–3 列并保存，使用上移、下移及移除管理图表。重启后恢复配置，图表显示当前数据。
12. 「导出中心」下载数据 CSV、含字段定义的原始 JSON、统计 CSV；趋势 JSON 在统计页面下载；PNG 在图表页面下载。浏览器下载目录由浏览器决定，验收自动化下载固定保存项目 exports；正式录制时请把浏览器下载目录设置为项目 exports。
13. 重启验证：记录实验名称和行数，Ctrl+C 停服，重新启动，选择同一项目查看数据和仪表盘。不要删除 data/labledger.sqlite3。

## 常见情况

- 无数据：先创建表并新增记录或加载模拟数据。
- 数字/日期无效：数字必须有限；日期格式 YYYY-MM-DD。错误值允许保存，但会提示。
- CSV 无法导入：检查字段名、重复表头、分隔符与编码 UTF-8/GB18030。
- 保存冲突：另一窗口已修改，刷新后重新编辑。
- 文件权限或磁盘错误：查看 logs/app.log，确认目录可写及剩余空间。
- PNG 中文：Windows 优先 Microsoft YaHei / SimHei。其他平台需安装 Noto Sans CJK SC 等中文字体。

## 数据备份

关闭应用后可以复制 data 目录备份；源码发布不包含个人数据库，首次运行自动初始化空库。V2/2.1 的“系统设置”支持创建和下载 SQLite 备份、上传备份后确认恢复；恢复前会保存当前库副本。也支持导出完整实验项目 JSON，并导入为隔离副本；包含数据版本和历史。不要在运行过程中手工替换数据库文件。

## 2.1 推荐流程

1. 加载算法性能合成演示，或创建实验、数据表并上传模板 CSV。
2. 在“实验详情”保存研究目的、方法、变量和条件；在“数据清洗”预览并保存处理版本。
3. “专业统计”保存分析快照，“实验对比”固定条件后比较；“高级图表”导出 PNG/SVG/HTML。
4. “数字档案”封存并一键重跑，查看哈希与数值差异；异常诊断和方案结果对照位于同页标签。
5. “智能分析”编辑并保存结论；“报告中心”生成并下载 ZIP。数据或结论变化后重新生成报告。
6. 在“系统设置”导出项目及数据库备份，重启后核对行数和历史。清洗/恢复会生成版本，异常候选不会默认删除。
